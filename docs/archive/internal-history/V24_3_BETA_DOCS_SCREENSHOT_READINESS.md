# v24.3 — Beta Documentation & Screenshot Readiness

v24.3 keeps the public beta feature surface frozen and improves the release-facing documentation.

## Goals

- Make the README understandable to a first-time GitHub visitor.
- Make the beta demo path explicit: install -> select/download model -> load -> quick test -> copy `/v1` endpoint.
- Define the five required screenshots for public beta.
- Keep all guidance user-facing and avoid milestone/history language in live product copy.

## Changes

- README now includes a public beta demo path.
- README now lists the required screenshot filenames and what each should show.
- Release kit package command now references `v24.3`.
- `docs/screenshots/README.md` was updated with the final screenshot contract.
- Added `docs/screenshots/CAPTIONS.md` for README/release captions and alt text.
- Added `docs/demo/public-beta-walkthrough.md` for beta testers and launch videos.
- Smoke checks now require this v24.3 doc.

## Non-goals

- No new daily-mode card.
- No new product feature.
- No screenshot images generated by code. Real screenshots should be captured from a running app.

## Verification

Run:

```bash
./scripts/launch-check.sh
./scripts/smoke.sh
./scripts/check.sh
```

Then follow `docs/BETA_BUG_BASH.md` and `docs/demo/public-beta-walkthrough.md`.
