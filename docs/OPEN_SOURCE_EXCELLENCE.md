# Open Source Excellence Pass

v7 is an open-source credibility pass. It intentionally avoids large product scope and focuses on making the project understandable, safe, and contributor-friendly.

## What changed in v7

- Rewritten README with public positioning.
- Added one-command dev script.
- Added one-command check script.
- Added environment doctor script.
- Added architecture diagram doc.
- Added demo flow docs.
- Added project comparison doc.
- Added maintainer release checklist.
- Expanded CI to run backend lint and frontend typecheck.
- Added agent prompts for the next milestone.

## Why this matters

Open-source users usually decide quickly whether a project is serious. The first impression should answer:

1. What is this?
2. Why does it exist?
3. How is it different?
4. Can I run it quickly?
5. Is it safe?
6. Can I contribute without guessing?

v7 is designed to answer those questions before adding more feature surface.
